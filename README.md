# Basic Pong Game

A simple Pong game made with Python and Pygame.

## How to Play
- **Player 1 (Left paddle)**: `W` (up) / `S` (down)
- **Player 2 (Right paddle)**: `↑` (up) / `↓` (down)

First player to score gets a point. Play as long as you want!

## Requirements
- Python 3
- Pygame library

## How to Launch

1. Clone the repository:
   ```bash
   git clone https://github.com/Bloodstarblade/pong-game.git
   cd pong-game
   ```

2. Install Pygame:
   ```bash
   pip install pygame
   ```

3. Run the game:
   ```bash
   python pong.py
   ```

Have fun!
